# 01 — Xətti cəbr

> **AI-da rolu:** Neyron şəbəkənin hər qatı əslində matris vurmasıdır: $y = Wx + b$.
> Şəkillər, sözlər, istifadəçilər — hamısı vektor kimi təsvir olunur.

## Mövzular

- [ ] Vektorlar: toplama, skalyar hasil, norma ($\|x\|_2$)
- [ ] Matrislər: vurma, transpoze, tərs matris
- [ ] Xətti asılılıq, baza, rank
- [ ] Determinant
- [ ] Məxsusi qiymət və məxsusi vektor ($Av = \lambda v$)
- [ ] SVD (Singular Value Decomposition)
- [ ] PCA — ölçü azaltma
- [ ] Kosinus oxşarlığı (embedding-lər üçün)
