# 🤖 AI — Süni İntellekt: Dərs, Tədqiqat və İmtahan Hazırlığı

Bu repo mənim **Süni İntellekt** dərsim və tədqiqatlarım üçün şəxsi bilik bazamdır.
Məqsəd: öyrəndiklərimi sistemli qeyd etmək, riyazi əsasları dərindən başa düşmək və imtahana hazır olmaq.

---

## 📂 Struktur

| Qovluq | Nə üçündür |
|---|---|
| [`00-materials/`](00-materials/) | Müəllimin slaydları, PDF-lər, xam materiallar |
| [`01-lectures/`](01-lectures/) | Hər mühazirə üçün öz sözlərimlə konspekt |
| [`02-math/`](02-math/) | 🧮 AI-ın riyazi əsasları — ayrıca, dərindən |
| [`03-exam-prep/`](03-exam-prep/) | Sual bankı, cheat-sheet, sınaq imtahanları, səhvlərim |
| [`04-research/`](04-research/) | Məqalələr və tədqiqat qeydləri |
| [`05-code/`](05-code/) | Notebook-lar, alqoritmlərin sıfırdan implementasiyası |
| [`journal/`](journal/) | Gündəlik öyrənmə qeydləri (hər gün kiçik bir addım) |
| [`templates/`](templates/) | Konspekt, riyaziyyat və məqalə şablonları |

---

## 🔁 İş axını

```
Material gəlir  →  00-materials/ (xam fayl)
      ↓
Konspekt yazılır  →  01-lectures/  (öz sözlərimlə)
      ↓
Riyazi hissə ayrılır  →  02-math/  (düsturlar, isbatlar, misallar)
      ↓
Suallar çıxarılır  →  03-exam-prep/questions.md
      ↓
Gündəlik qeyd  →  journal/YYYY-MM-DD.md
```
