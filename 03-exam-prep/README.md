# 🎯 İmtahan hazırlığı

| Fayl | Məzmun |
|---|---|
| [`questions.md`](questions.md) | Sual bankı — hər mövzudan suallar və cavablar |
| [`cheatsheet.md`](cheatsheet.md) | Ən vacib düsturlar və tərif — imtahandan əvvəl 15 dəqiqəlik təkrar |
| [`mistakes.md`](mistakes.md) | Səhv etdiyim suallar və niyə səhv etdim |
| `mock-exams/` | Sınaq imtahanları (vaxt ölçərək həll) |

## Strategiya

1. Hər mühazirədən sonra → `questions.md`-ə 3–5 sual.
2. Həftədə bir dəfə → sualları cavaba baxmadan həll et.
3. Səhv etdiklərini → `mistakes.md`-ə yaz (ən çox öyrədən fayl budur!).
4. İmtahandan 1 həftə əvvəl → sınaq imtahanı.
