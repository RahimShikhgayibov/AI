## Strategiya

1. Hər mühazirədən sonra → `questions.md`-ə 3–5 sual.
2. Həftədə bir dəfə → sualları cavaba baxmadan həll et.
3. Səhv etdiklərini → `mistakes.md`-ə yaz (ən çox öyrədən fayl budur!).
4. İmtahandan 1 həftə əvvəl → sınaq imtahanı.
