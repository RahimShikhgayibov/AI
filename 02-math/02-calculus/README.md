# 02 — Analiz (Calculus)

> **AI-da rolu:** Model səhvini azaltmaq üçün "hansı istiqamətə dəyişim?" sualına
> törəmə cavab verir. Backpropagation = zəncir qaydasının ağıllı tətbiqi.

## Mövzular

- [ ] Funksiya, limit, kəsilməzlik
- [ ] Törəmə və onun mənası (meyl)
- [ ] Xüsusi törəmələr ($\frac{\partial f}{\partial x}$)
- [ ] Qradiyent vektoru ($\nabla f$)
- [ ] Zəncir qaydası (chain rule) → backpropagation
- [ ] Yakobian və Hessian matrisləri
- [ ] Aktivasiya funksiyalarının törəmələri (sigmoid, ReLU, tanh)
- [ ] Teylor sırası (yaxınlaşma)
