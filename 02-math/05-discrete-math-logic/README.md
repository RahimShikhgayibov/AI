# 05 — Diskret riyaziyyat və məntiq

> **AI-da rolu:** Klassik AI (axtarış, planlama, bilik təsviri) qraflar və məntiq
> üzərində qurulub. BFS, DFS, A* — hamısı qraf alqoritmləridir.

## Mövzular

- [ ] Çoxluqlar və funksiyalar
- [ ] Mülahizələr məntiqi: $\land, \lor, \lnot, \rightarrow$, doğruluq cədvəlləri
- [ ] Predikatlar məntiqi: $\forall, \exists$
- [ ] Nəticə çıxarma qaydaları (modus ponens, rezolyusiya)
- [ ] Qraflar və ağaclar
- [ ] Axtarış mürəkkəbliyi, Big-O
- [ ] Kombinatorika (vəziyyət fəzasının ölçüsü)
- [ ] Heuristikalar: admissible, consistent
