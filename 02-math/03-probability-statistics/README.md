# 03 — Ehtimal nəzəriyyəsi və statistika

> **AI-da rolu:** Dünya qeyri-müəyyəndir. AI "bu şəkil 92% ehtimalla pişikdir" deyir —
> bu, ehtimal dilidir. Bayes teoremi AI-ın ən mühüm düsturlarından biridir.

## Mövzular

- [ ] Ehtimalın əsasları, hadisələr, aksiomlar
- [ ] Şərti ehtimal və asılı olmayan hadisələr
- [ ] Bayes teoremi: $P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}$
- [ ] Təsadüfi kəmiyyətlər, gözləmə ($E[X]$), dispersiya
- [ ] Paylanmalar: Bernulli, binomial, normal (Qauss)
- [ ] Birgə və marginal paylanmalar
- [ ] Maksimal həqiqətəbənzərlik (MLE)
- [ ] Bayes şəbəkələri, Naive Bayes
- [ ] Markov zəncirləri / HMM
